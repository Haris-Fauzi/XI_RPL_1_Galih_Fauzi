langkah langkah collab dengan github

  1. 1.add repository
  2. 2.add collaborator
  3. 3.collaborator akan menerima email notifikasi
  4. 4.setelah mengadd satu sama lain cari repository anggota collab yang mau diedit
  5. 5.setelah membuka repositorynya cari code disamping dan salin urlnya
  6. 6.buka terminal laragon
  7. 7.ketik git clone url tadi
  8. 8.setelah clone selesai ketik ls diterminal untuk menemukan foldernya
  9. 9.ketik cd untuk menggunakan folder
  10. 10.ketik code . untuk membuka visual studio code
  11. 11.buat file baru yg bernama collab.html
  12. 12.dan disuruh membuat file collab untuk menghubungkan website github
  13. 13.setelah selesai buka terminal lagi
  14. 14.selanjutnya ketik git add collab.html untuk menambahkan ke repository
  15. 15.ketik git commit -m "add collab.html" untuk menyimpan perubahan
  16. 16.ketik git push url github untuk menambahkan ke github
